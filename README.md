## Como rodar
Site 100% estático, sem build. Basta abrir o `index.html` ou servir a pasta:

```powershell
# Opção 1: abrir direto
start index.html

# Opção 2: servidor local com Python
python -m http.server 8000
# abrir http://localhost:8000
```
